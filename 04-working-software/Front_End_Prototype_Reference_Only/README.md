# VMS Phish-Guard Front-End Prototype

This is a static Sprint 1 front-end prototype for the VMS Phish-Guard project.

## What is included

- Dashboard / overview section
- Campaign setup mockup
- Safe landing-page simulation
- Training module cards
- Interactive quiz question
- Campaign report mockup
- Responsive navigation and mobile-friendly layout

## How to run

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. Optional: use the VS Code Live Server extension for easier previewing.

## Notes

This prototype does not collect, store, or transmit real credentials. It is designed for an authorized academic phishing awareness and training project.
